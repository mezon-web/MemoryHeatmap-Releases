MEMORY / PROCESS MAP

メモリの使用量と変化を読む。

四角の大きさで「どのアプリが使っているか」、色で「直近に増えたか・減ったか」を確認します。PC 全体の状況と、アプリごとの内訳を一画面に表示する監視ツールです。

更新 2 秒増減比較 約 10 秒配布 単一 EXE・.NET 非同梱版 1.0.0 プレビュー

01起動する

  1. 配布 ZIP を展開し、MemoryHeatmap.exe をダブルクリックします。
  2. 数秒で現在の使用量が表示されます。増減が出るまでは、そのまま約 10 秒待ちます。
  3. 終了するときはウィンドウ右上の × を押します。監視処理も終了します。
.NET 10 Desktop Runtime（Windows / x64）が必要です。
実行環境は EXE に同梱していません。未導入の場合は Microsoft の .NET 10 配布ページで「.NET Desktop Runtime」の Windows x64 を選んでください。通常の .NET Runtime だけでは WPF アプリを実行できません。

通常権限で動作します。起動後のネットワーク接続は不要です。Windows 11 22H2 の 2023 年 9 月更新以降のメモリ API を使用します。

02マップを読む

四角の面積はアプリ専用の RAM 使用量です。同じ実行ファイルのフルパスから起動した複数のプロセスを、一つの四角に合算します。別の場所にある同名アプリは別々に表示します。

赤：増加緑：減少暗色：変化小・計測中

色は約 10 秒前との差です。1 MiB 未満の変化は暗色にし、増減の数値には小さな差も表示します。増減率が大きいほど色が強くなります。小さい四角の文字は省略されますが、マウスを重ねると詳細を読めます。

初回は使用量順で配置し、その後は既存の並びを保ちます。使用量によって四角の境界は動きます。新しいアプリは末尾に追加され、終了したアプリは消えます。

マップ全体の面積は、表示中に取得できた専用 RAM の合計を基準にしています。検索で絞り込むと面積は再計算されます。上部にある PC 全体の使用量とは一致しません。

03プロセスを調べる

四角か右下のアプリ一覧を選択すると、右側にアプリ名、実行ファイルのパス、専用 RAM、増減、コミット量を表示します。その下の表で PID ごとの使用量と増減を確認できます。

プロセス行にマウスを重ねると、そのプロセスのコミット量、共有分を含むワーキングセット、取得状態を表示します。長いパスもマウスを重ねると全文を確認できます。

取得不可や使用量 0 のアプリには面積がありません。右下の一覧から選択してください。狭いウィンドウでは右側のパネルをスクロールできます。

04検索・一時停止

操作動作
検索欄アプリ名・PID・実行ファイルのパスを部分一致で絞り込みます。英字の大文字・小文字は区別しません。
クリア検索条件を消し、全アプリへ戻します。
一時停止新しい計測を止め、現在の表示値を維持します。検索・選択はそのまま使えます。
再開計測を再開します。古い差と混ざらないよう、約 10 秒分の比較履歴を取り直します。
キー操作
Ctrl + F検索欄へ移動
Esc検索欄にいるとき、検索を解除
Ctrl + Space一時停止／再開
矢印・Home・Endマップにフォーカスがあるとき、アプリの選択を移動

05数値の定義

表示意味
PC 全体の使用量総物理メモリから利用可能量を引いた値。OS や共有メモリを含みます。
利用可能量すぐ再利用できる RAM。空き領域のほか、再利用できるスタンバイメモリも含みます。
物理メモリOS が利用できる物理メモリの総容量。搭載 RAM の公称値と異なることがあります。
専用 RAMプライベートワーキングセット。現在 RAM にあり、そのプロセス専用となっているメモリです。
コミット量そのプロセスのプライベートなコミット済みメモリ。ページファイルへ退避した分も含むため、RAM 使用量とは異なります。
増減 / 10 秒10 秒以上前の直近サンプルとの差。通常は 10～12 秒です。アプリ単位ではプロセスの追加・終了による変化も含みます。

単位は MiB（1,048,576 バイト）、GiB（1,073,741,824 バイト）です。タスクマネージャーとは集約方法、更新時刻、列の定義が異なるため、数値が完全には一致しないことがあります。

06表示に迷ったら

「計測中」のまま色が付かない

起動直後や再開直後は約 10 秒待ってください。新しく起動したアプリも履歴を集めます。スリープ復帰などで計測の間隔が空いた場合は履歴を取り直します。増減が 1 MiB 未満なら、計測後も暗色です。

「取得不可」「一部取得不可」「*」が出る

通常権限では保護プロセスや別ユーザーのプロセスを取得できない場合があります。取得失敗を 0 として計算せず、取得できた合計には * を付けます。一部取得不可のグループは増減比較を保留します。起動時刻を取得できない場合は「比較不可」と表示します。

検索しても見つからない

検索をクリアし、右下の一覧を確認してください。パスを取得できないプロセスは、同名でも PID ごとに分かれます。既に終了したプロセスは次回更新で消えます。

起動できない

Windows 11 x64 と .NET 10 Desktop Runtime x64 を確認してください。ZIP の中から直接起動せず、展開した EXE を使います。アプリのインストールや管理者権限は不要です。

メモリを解放したい

このアプリは表示・分析専用です。メモリ解放やプロセス停止の操作はありません。設定の常駐登録や計測履歴の保存も行いません。
