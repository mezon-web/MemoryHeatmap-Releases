# MemoryHeatmap v1.2.0

「空き領域を表示」を追加したプレビュー版です。

- ON ではマップ全体を物理メモリ総量として表示。利用可能 (空き) は左端の上下いっぱいの長方形で、幅は利用可能量 ÷ 総容量です。
- 右側にアプリと「その他の使用分」を表示。その他は PC 使用量から全アプリの取得済み専用 RAM を引いた残りで、OS・共有分・取得不可などを含みます。
- 検索から外れたアプリは「検索対象外」に集約し、検索中も空きの幅と対象アプリの面積比を維持します。
- 内訳が一致しないときは「使用中（内訳確認中）」へまとめ、次の更新を待ちます。
- 一時停止中も即時に切り替え可能。初回 OFF、以後は EXE の隣の `MemoryHeatmap.settings.json` に保存します。
- 保存できない場合は「設定未保存」と表示。その場の表示切り替えは有効です。
- 日本語説明書と画面例を更新しました。

利用可能量には再利用できるスタンバイメモリを含みます。アプリの色は従来どおり約 10 秒の増減です。表示専用領域はプロセス操作の対象にはなりません。

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。
旧版を閉じて、新しい ZIP を展開した MemoryHeatmap.exe を起動してください。設定を引き継ぐ場合は EXE と一緒に設定ファイルを移動してください。

- `MemoryHeatmap-v1.2.0-win-x64.zip` — アプリと日本語説明書
- `MemoryHeatmap-v1.2.0-win-x64.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmap-v1.2.0-manual.html` — 8 章・8 画面の単一 HTML 説明書
