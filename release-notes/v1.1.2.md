# MemoryHeatmap v1.1.2

操作確認画面のボタン名を分かりやすくしたプレビュー版です。

- 「操作可能な対象を選択」→「全選択」
- 操作前の「キャンセル」→「閉じる」
- 実行中は「中止」、処理後は「閉じる」と表示。
- 日本語説明書と画面例を更新。

既存の架空データ UI 検査 69 項目、隔離デスクトップでの実画面、単独 EXE の起動・正常終了、Chrome / Edge での説明書のオフライン操作を確認しました。
[検証記録](https://github.com/mezon-web/MemoryHeatmap-Releases/blob/main/validation-v1.1.2.md) に方法と範囲を記載しています。

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。
旧版を閉じて、新しい ZIP を展開した MemoryHeatmap.exe を起動してください。

- `MemoryHeatmap-v1.1.2-win-x64.zip` — アプリと日本語説明書
- `MemoryHeatmap-v1.1.2-win-x64.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmap-v1.1.2-manual.html` — 画像付きの単一 HTML 説明書

開発ソースは非公開で管理しています。GitHub が自動生成する Source code ZIP は公開案内文書です。
