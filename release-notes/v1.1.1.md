# MemoryHeatmap v1.1.1

右クリックメニューの区切り線が右へ寄り、明るく表示されていた問題を修正したプレビュー版です。
左右の余白を揃え、項目の文字位置に合わせた暗めの細い線にしました。

![修正後のメニュー（架空データ）](https://raw.githubusercontent.com/mezon-web/MemoryHeatmap-Releases/main/images/menu.png)

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。
旧版を閉じて、新しい ZIP を展開した MemoryHeatmap.exe を起動してください。

- `MemoryHeatmap-v1.1.1-win-x64.zip` — アプリと日本語説明書
- `MemoryHeatmap-v1.1.1-win-x64.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmap-v1.1.1-manual.html` — 画像付きの単一 HTML 説明書

開発ソースは非公開で管理しています。GitHub が自動生成する Source code ZIP は公開案内文書です。
