# MemoryHeatmap v1.1.0

右クリックから、選択したアプリ・プロセスのメモリ整理とタスク終了を行えるプレビュー版です。

## 追加機能

- 四角・アプリ一覧・PID 行の右クリックメニュー。Shift+F10 またはメニューキーにも対応。
- 「メモリを整理…」で対象 PID を選び、操作直前・直後の専用 RAM と実行結果を表示。コミット量は行の詳細で確認。
- 「タスクを終了…」で対象と未保存データの警告を確認し、選択した PID を強制終了。
- 「ファイルの場所を開く」で実行ファイルを Explorer で選択表示。
- 手動操作の印をマップ・詳細・ツールチップへ表示。記録は最大 32 件・約 2 分だけ保持。

四角からは対象を未選択で確認画面を開き、PID 行からはその 1 件だけを選択済みで開きます。
確認画面を開いた後の新しいプロセスや、子プロセスを自動で追加しません。
システム・重要な処理、自身、別ユーザー・サービス・別セッション、身元や権限を確認できない対象は操作しません。
実行直前にも PID・起動時刻・パスと保護条件を確認します。権限の昇格は行いません。

**タスク終了は強制終了です。未保存のデータが失われる可能性があります。**
メモリ整理はワーキングセットの縮小で、確保済みコミット量は残ります。再アクセスで RAM 使用量が戻る場合があります。
自動整理・自動終了・常駐登録は行いません。

## 検証

コア・ネイティブ操作 30 項目、既存集約 31 シナリオ、旧処理との 240 フレーム比較、WPF / 回収制御 / 操作 86 項目を通過。
専用プローブの 128 MiB 確保、整理後のデータ保持と再アクセス、CPU 使用中のスキップ、UI からの整理・終了を確認しました。
Chrome / Edge で画像 6 枚・7 章の日本語説明書のオフライン操作も検査しています。
検証の方法・範囲・EXE の消費量は [検証記録](https://github.com/mezon-web/MemoryHeatmap-Releases/blob/main/validation-v1.1.0.md) に記載しています。

## 起動・更新

**Windows 11 x64 と .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。**
旧版を終了して、新しい ZIP を展開した MemoryHeatmap.exe を起動してください。

- `MemoryHeatmap-v1.1.0-win-x64.zip` — 単一 EXE と日本語説明書
- `MemoryHeatmap-v1.1.0-win-x64.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmap-v1.1.0-manual.html` — 画像付きの単一 HTML 説明書

開発ソースは非公開リポジトリで管理しています。GitHub の自動生成 Source code ZIP は、この公開案内リポジトリの文書です。
