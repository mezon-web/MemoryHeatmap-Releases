# MemoryHeatmap v1.2.1

空き領域だけを追加し、右側のアプリ表示を従来の動きに戻しました。

- 左端に現在の利用可能 (空き) を表示。右側はアプリ同士の専用 RAM 比で配置します。
- 「その他の使用分」「検索対象外」「内訳確認中」の領域を取り除きました。
- 検索すると右側を検索結果のアプリで再計算します。1 件なら右側をそのアプリが占めます。空きの幅は検索に影響されません。
- チェックボックスを「ヒートマップ」の見出しのすぐ右に移動しました。
- 「専用 RAM 合計 / 10 秒差」を、上部の PC 全体の使用量の下へ移動しました。
- 説明書と画面例を更新しました。

空きの幅は利用可能量 ÷ 総物理メモリです。アプリの面積は右側の中での相対比を示します。
利用可能量には再利用できるスタンバイメモリも含みます。アプリの数値・色・選択・右クリック操作は従来どおりです。
設定は EXE の隣の `MemoryHeatmap.settings.json` に保存します。既存の設定を引き継げます。

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。
旧版を閉じて、新しい ZIP を展開した MemoryHeatmap.exe を起動してください。

- `MemoryHeatmap-v1.2.1-win-x64.zip` — アプリと日本語説明書
- `MemoryHeatmap-v1.2.1-win-x64.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmap-v1.2.1-manual.html` — 画像付きの単一 HTML 説明書
