# MemoryHeatmap v1.2.4

「空き領域を表示」を検索の左へ移動し、設定に関する警告ラベルを省いて操作欄を整理しました。

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。
旧版を閉じて、新しい ZIP を展開した MemoryHeatmap.exe を起動してください。
表示設定を引き継ぐ場合は、EXE の隣の MemoryHeatmap.settings.json を残してください。

- `MemoryHeatmap-v1.2.4-win-x64.zip` — アプリと日本語説明書
- `MemoryHeatmap-v1.2.4-win-x64.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmap-v1.2.4-manual.html` — 画像付きの単一 HTML 説明書

開発ソースは非公開で管理しています。GitHub が自動生成する Source code ZIP は公開案内文書です。
