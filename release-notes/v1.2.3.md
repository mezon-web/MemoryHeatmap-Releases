# MemoryHeatmap v1.2.3

アプリ自身の更新処理を軽量化しました。

- 集計・履歴の作業領域を再利用し、監視中に発生する一時データを削減。
- プロセス名の再生成や、少数 PID の並べ替えにかかる負荷を削減。
- 集計とマウス位置の判定を整理し、内部の保守性を改善。

表示内容、2 秒更新、約 10 秒の増減比較、空き領域表示、右クリック操作は引き続き利用できます。

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。
旧版を閉じて、新しい ZIP を展開した MemoryHeatmap.exe を起動してください。
表示設定を引き継ぐ場合は、EXE の隣の MemoryHeatmap.settings.json を残してください。

- `MemoryHeatmap-v1.2.3-win-x64.zip` — アプリと日本語説明書
- `MemoryHeatmap-v1.2.3-win-x64.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmap-v1.2.3-manual.html` — 画像付きの単一 HTML 説明書

開発ソースは非公開で管理しています。GitHub が自動生成する Source code ZIP は公開案内文書です。
