# MemoryHeatmap v1.0.0

Windows 11 x64 向けの初回プレビュー版です。アプリのメモリ使用量を面積で、約 10 秒前からの増減を色で確認できます。

## 内容

- 専用 RAM（プライベートワーキングセット）のツリーマップを 2 秒ごとに更新。
- フルパス単位の集約、PID ごとの内訳、コミット量、PC 全体の使用量・利用可能量。
- 検索、一時停止／再開、ツールチップ、キーボード操作。
- 濃いグレーの背景、細い罫線、控えめな琥珀色を使った日本語 UI。
- 画像埋め込みのオフライン HTML 説明書と、テキスト説明書を同梱。

## 起動

**.NET 10 Desktop Runtime x64 が必要です。.NET は同梱していません。**

`MemoryHeatmap-v1.0.0-win-x64.zip` を展開し、`MemoryHeatmap.exe` を実行してください。
Windows 11 x64 / 22H2 の 2023 年 9 月更新以降に対応します。通常権限、オフラインで動作します。
未導入の実行環境は [Microsoft](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) から導入できます。

## 確認済みの範囲

集約・PID 再利用・取得不可・履歴・面積計算、WPF の 43 チェック、1,500 アプリ、実メモリ 128 MiB の確保／解放に伴う面積と赤／緑の変化を検証しました。
最終 EXE を単独フォルダーから起動し、実ウィンドウの描画と正常終了を確認しました。
HTML 説明書は Chrome / Edge のオフライン状態で確認しています。

UI 検証は隔離デスクトップ上の WPF イベント・状態検査です。100～200% 相当の検査は画像出力 DPI によるもので、実モニター間の移動や OS の拡大率切り替えは未検査です。
詳細と消費リソースの参考値は [検証記録](https://github.com/mezon-web/MemoryHeatmap-Releases/blob/main/validation-v1.0.0.md) を参照してください。
