# MemoryHeatmap v1.2.5

「空き領域を表示」のチェックボックスと文字を「検索」と上下中央で揃え、項目間の余白を少し広げました。

使い方は HTML にまとめました。起動・マップの見方・アプリの確認を3ステップで案内し、主な操作と困ったときの対処を読みやすく整理しています。

Windows 11 x64 / .NET 10 Desktop Runtime x64 が必要です。実行環境は同梱していません。
旧版を閉じて、新しい ZIP を展開した MemoryHeatmap.exe を起動してください。
表示設定を引き継ぐ場合は、EXE の隣の MemoryHeatmap.settings.json を残してください。

- `MemoryHeatmap-v1.2.5-win-x64.zip` — アプリと日本語 HTML 説明書
- `MemoryHeatmap-v1.2.5-win-x64.zip.sha256.txt` — ZIP の SHA-256
- `MemoryHeatmap-v1.2.5-manual.html` — 画像付きの単一 HTML 説明書

開発ソースは非公開で管理しています。GitHub が自動生成する Source code ZIP は公開案内文書です。
